# xray-pilot v0.9.3

本版修复节点误报待同步和过期用户撤权状态，并补全 VLESS + Reality 出站编辑。

## 新增

- 路由模板可直接选用 VLESS + Reality 落地机预设，在表单中设置指纹和 SpiderX 路径。

## 修复

- 编辑节点备注会保留当前同步状态，编辑用户备注会保留最新分组。用户授权变更只标记受影响的节点。
- 离线节点保留待撤权任务，恢复连接后继续确认。同步任务被接管后，旧任务的失败或回滚消息不会覆盖新结果。
- 从 JSON 切回表单编辑简写 VLESS 出站时，会保留已有账号、加密参数和扩展配置。

## 升级

- 替换面板程序并重启，数据库会自动添加过期撤权记录。
- 手写 VLESS 出站请为每个用户显式填写 `encryption`。未使用 VLESS Encryption 时填写 `"none"`。
