# xray-pilot v0.7.2

修复单节点协议端口修改导致全部节点待同步的问题，优化仪表盘统计布局、图表交互和移动端操作。

发布日期：2026-11-17。

## 协议配置与同步

- 修改某个节点的协议端口、参数或密钥，以及绑定、解绑协议时，仅将目标节点标记为待同步，不再影响其他节点的状态。
- 修改共享协议模板仅影响已绑定节点；只修改默认端口时，已有独立端口覆盖的节点不受影响。新增未绑定模板、修改名称或备注，以及重复保存相同内容不触发同步。
- 重复保存相同的 Reality 私钥不再因加密结果变化而误判配置变更。协议停用、节点协议锁定和保存失败时保留正确的同步范围。
- 协议变更与同步状态在同一数据库事务中保存，避免保存失败后残留错误的待同步状态。

## 仪表盘

- 日期选择、节点和用户筛选、刷新按钮统一到顶部工具栏；移除筛选旁独立的搜索输入框，下拉选项使用完整宽度。
- 统一为八张数字卡片，顺序为：节点总数、健康节点、有用量节点、启用用户、上行流量、下行流量、总流量、活跃用户。标题去掉重复的“区间”，小字说明区分当前状态与所选时间范围。
- 宽屏采用约 70% / 30% 布局：左侧依次为用量趋势、用量排名、最近操作与异常，右侧为节点健康；较窄屏幕自动改为上下排列，数字卡片随宽度调整列数。
- 趋势图日期统一显示为 `YYYY-MM-DD`，小时粒度补充时间；保留节点／用户维度、流量方向、筛选联动和缺采断点。
- 用量排名改为柱状图，总用量按上行、下行堆叠展示，可切换方向、查看数值与占比、点击进入对象明细；窄屏通过分页展示排名。
- 最近六条操作与异常完整展示；节点健康每行一个节点，取消列表内部固定高度滚动，长内容自然换行。
- “统计说明”和采集失败次数移至趋势图标题栏，在维度选择之前。点击后从入口右下方弹出说明浮层，不增加图表高度；支持自动避让屏幕边缘、外部点击、关闭按钮和 Esc 关闭。

## 移动端

- 节点管理顶部操作按钮空间不足时自动换行，移动端左对齐，按钮文字与图标不再被挤压。宽屏保留右侧操作布局。
- 仪表盘筛选、趋势图工具栏与数字卡片适配窄屏，保留原有快捷日期选择和图表操作。

## 升级说明

- 继续支持 SQLite，无新增数据库结构变更。已有误标的待同步状态需要通过同步流程重新核验，不直接批量清除。
- 一键安装继续获取最新正式版本；一键接入的 Xray 版本仍读取后台稳定版本设置，未设置时默认为 `26.3.27`。修改设置后需重新生成接入命令，现有节点版本不会自动改变。
- 路由分流、配置同步、失败恢复与订阅生成行为保持不变。本地演示数据和开发文档不包含在发布包或仓库中。
