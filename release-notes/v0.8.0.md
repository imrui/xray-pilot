# xray-pilot v0.8.0

## 新增

- 路由模板支持自定义出站、服务端 DNS、负载均衡和健康探测。可切换表单与 JSON、按节点覆盖出站参数，并用节点上的 Xray 预检草稿。
- 节点配置与面板记录冲突时，超级管理员可先核对脱敏后的配置，再决定是否接管并同步。

## 管理界面

- 修复跨页搜索遗漏，增加一键清空，统一列表分页。加宽编辑抽屉，精简设置和日志页说明，节点同步失败时可按具体原因排查。

## 从 v0.7.2 升级

- 备份数据库并保留原 MasterKey，替换面板程序后重启 `xray-pilot` 服务。数据库自动迁移，保留已有节点和路由绑定。
- 旧版 v1/v2 路由继续支持原有规则字段的大小写写法。新模板需绑定已发布版本并同步后才会在节点上生效。
- 升级本身不会下发配置、重启或升级节点上的 Xray。已排队的同步、自动恢复和过期用户撤权仍按原策略执行。
