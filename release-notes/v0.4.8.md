# xray-pilot v0.4.8

新增 HTTP / SOCKS5 代理协议：节点可对外提供明文代理端口，专供运行时程序使用（IP 白名单 + 可选认证），与订阅体系完全隔离。已在真实节点完成端到端验证。

## 新增

### HTTP / SOCKS5 代理协议

面向"给程序用代理"的场景：协议配置页新建 HTTP 或 SOCKS5 模板，需要的节点绑定即开启，程序侧 `http_proxy=http://节点IP:18080` 或 socks5 直连使用。

- **IP 白名单**（`allowed_ips`）：支持单 IP 与 CIDR 网段混写，通过 xray routing `source` 规则实现——白名单内来源 → direct，其余同入站流量 → blackhole
- **可选认证**（`accounts`）：填入 `[{"user":"...","pass":"..."}]` 启用用户名/密码认证（SOCKS5 自动切 `auth: password`），与白名单是"或"的关系
- **内网目标开关**（`allow_private`，默认 false）：控制白名单来源能否通过代理访问内网目标地址；默认拦截（云元数据、节点本机服务均不可达），显式开启后该入站的放行规则前置于 `geoip:private` 屏蔽。支持节点级覆盖（显式 `false` 可覆盖模板的 `true`）
- **节点级覆盖**：白名单 / 账号 / 内网开关 / 端口均可在节点密钥中覆盖模板值

### 安全护栏

- 白名单与认证**均未配置时拒绝生成**该入站（防止公网开放代理被扫描滥用）
- 白名单条目非法（非 IP/CIDR）时拒绝生成，避免 xray 整体起不来；两类问题均转为同步预览中的 warning，不影响其他协议
- **订阅隔离**：http/socks 不出现在订阅 URI / Clash / sing-box 输出与订阅信息页，由测试用例锁死；仅绑代理协议的节点自动从订阅中隐藏

### 体验

- 协议下拉新增 HTTP / SOCKS5 选项，切换时自动填入白名单模板与默认端口（18080 / 11080）
- 新增协议时配置名默认按协议类型填充，手动改名后切换协议不覆盖

## 说明

- 代理账号与用户系统无关，用户增删的 gRPC 即时生效路径自动跳过代理入站
- SOCKS5 当前仅代理 TCP（`udp: false`）
- 公网部署建议在云安全组对代理端口额外做一层来源限制，双保险
