# 未发布：路由配置与节点同步

路由分支待复核，尚未合并或发布。正式版本号与发布日期在确认发布时填写。

## 路由配置

- 新增路由模板、草稿、不可变版本，以及节点／分组／全局的绑定和继承管理。
- 分别配置“强制 IPv4 域名”和“强制 IPv6 域名”。未命中规则时使用普通 `freedom / direct`，不强制地址族；规则与客户端通过 IPv4 或 IPv6 连接节点无关。
- 强制地址族不自动回退，也不转换 IP 字面量。没有 IPv6 出口的节点会在同步前拒绝需要 IPv6 的配置，保留正在运行的配置。
- 支持受校验的自定义域名、目标 IP／CIDR 路由。匹配顺序为系统保护规则、自定义规则、强制 IPv4 域名、强制 IPv6 域名；两组域名重叠时 IPv4 优先。
- 提供“系统默认路由”和“AI 工具 / 流媒体分流”预设。后者包含 8 条 IPv4、3 条 IPv6 起始规则，需要 IPv6 出口，不自动绑定节点。预设可以复制为独立模板，参考列表不视为完整服务域名库，默认不纳入覆盖范围较广的 `domain:google.com`。

## 操作流程

- 模板采用列表和编辑抽屉，统一节点、协议与路由的操作习惯。保存草稿用于继续编辑；发布仅生成可选的固定版本，不自动升级已有节点绑定。
- 一个节点选择一份有效路由模板，同时仍可绑定多个协议。来源顺序为节点指定、分组指定、全局默认，再应用本节点覆盖；多个分组产生冲突时明确提示。
- “路由来源”提供继承、指定模板及版本、“基础路由（不使用模板）”。基础路由保留系统保护和协议规则，普通流量直连，不应用模板或节点路由覆盖。
- 本节点域名覆盖区分“继承模板”“自定义列表”“清空规则”。默认继承并展示固定版本中的只读域名；自定义替换整组列表，空白不能误保存为清空；清空只移除对应组的域名规则。已有覆盖不会随模板切换自动删除。
- 模板的“配置节点”抽屉区分点击预览和勾选批量操作。批量指定模板版本时保留每台节点的覆盖和配置路径。
- 配置同步统一保留在节点列表，支持单节点、批量和待同步节点操作。完整配置预览包含协议、用户、路由与出站，并展示配置来源和运行确认状态。
- 保存前可只读预览影响范围及继承内容；未保存的表单不会改写绑定或触发同步。保存后根据系统的手动／自动同步设置生效。
- 同步历史、预检、SNI 诊断和恢复操作归入节点管理，任务支持分页和结果核对。健康探测地址位于“系统设置 → 节点与同步”。

## 配置同步与恢复

- 完整同步包含目标 Xray 配置预检、原子替换、进程及管理接口检查；存在可用用户时进一步验证真实代理请求。
- 健康或重启失败时恢复符合当前授权的健康配置并重新启动。恢复不改写管理员绑定或期望版本，未完成目标保持待同步；自动恢复失败后停止循环重试。
- 恢复配置保留当前用户和密钥，避免重新启用已撤销授权。用户热更新先持久化授权，再应用差异，部分失败不会误报成功。
- 相同配置可凭有效运行证明原地核对，避免重复写入和重启。同一请求重复提交不创建额外任务；响应丢失后可核对结果。
- 通过节点锁、数据库租约和配置版本防止并发覆盖。只有有效配置变化的节点进入同步，单个节点失败不会阻止其他节点；分组冲突按节点报告。
- 过期用户撤权需相关节点确认生效或确认停止后才完成标记；离线节点保留待处理。已成功恢复当前授权的节点不会被额外停止。

## 兼容性与修复

- Reality 默认 SNI 改为 `www.apple.com`，用于新增协议模板、一键生成参数，以及未指定 SNI 时的回退。已有明确设置的协议 SNI 和节点覆盖保留原值。
- 移除开发阶段增加的全局、节点和用户 UDP 443 策略，恢复原有订阅行为：Reality 使用 `xtls-rprx-vision`，Clash／sing-box 正常保留对应节点；旧策略值不再生效。
- 首装和换机按安装器实际生成的配置建立一次性基线，兼容带入站的安装样例；安装前已有配置或之后被修改的文件不会被自动接管。首次预检失败可按已确认基线重试。
- 修复自定义目标 IP／CIDR 规则被误判为系统保护规则而无法下发的问题，保留私网、来源白名单及入站保护。
- 修复临时配置缺少 JSON 格式标识、仅剩管理接口时空端口检查异常，以及恢复后的配置被重复写入或重启等问题；快速核对同样检查 systemd 实际配置路径。
- 健康备份兼容 Python 3.6，代理探测不受环境免代理设置干扰。运维代理保留普通 direct 出站语义。
- 换机清理旧机器回执；删除最后一个已管理协议时可撤销旧监听；新 Reality 密钥默认生成非空 shortId。
- 一键接入支持通过 `NODE_IP` 指定面板可达的 IPv4／IPv6 地址，适用于局域网和 NAT 环境；非法地址在修改 SSH 配置前拒绝。

## 升级说明

- 默认部署继续使用 SQLite，PostgreSQL 为可选后端。
- 从旧版升级的存量节点保留基础路由，新建节点继承全局默认。预设只补齐缺失内容，不覆盖管理员修改，不改写已有全局绑定。
- 旧模板版本及健康恢复快照保留原有 IPv4 兜底行为。编辑旧模板时转为新版草稿：原先因关闭 IPv6 而走 IPv4 的域名会归入 IPv4 列表。保存、发布并选择新版本后才切换行为。
- 新版模板不再使用 IPv6 开关；旧节点存在对应开关覆盖时，需显式移除并检查两组域名列表。恢复继承、清空列表和基础路由含义不同。
- 首装基线登记需要配套的一键接入脚本。旧脚本仍可登记节点，但不会获得覆盖现有配置的初始化许可；发布时需同步面板与脚本。
