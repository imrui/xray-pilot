# xray-pilot v0.5.1

节点异常飞书群告警：节点出问题时自动推送到飞书群，恢复后再推一条。

## 新增

### 节点异常告警

- 系统设置 → 订阅与通知新增「节点告警」，复用已配置的飞书应用机器人，把卡片消息推送到指定群
- 告警类型（可分别勾选）：
  - **服务器不可达**：SSH 端口连接失败
  - **Xray 端口不通**：服务器能连上，但节点上的代理端口（TCP 类协议，按节点级端口覆盖计算）不通——xray 挂了、端口被防火墙挡了都会触发。Hysteria2 等 UDP 协议不探测
  - **配置同步失败**：失败 1 次即告警，下次同步成功后恢复
  - **面板到全部节点不可达**：同一轮检测所有节点都连不上时，只发这一条而不逐个刷屏（多见于面板出网或跨境链路故障）
- 防抖：连续失败 N 次（默认 3）才告警，连续成功 M 次（默认 2）才恢复；恢复消息附带异常持续时长
- 同一轮检测的多条变化合并成一张卡片；可选「未恢复时每隔 X 小时重复提醒」（默认关闭）
- 卡片配色：有新异常为红色，仅有重复提醒为橙色，仅有恢复为绿色；卡片内每行的 [异常] / [仍未恢复] / [恢复] 标签分别以红 / 橙 / 绿标注
- 发送失败会在下一轮自动重试；告警状态持久化，面板重启不会重复告警或丢失恢复消息
- 设置页可直接拉取机器人所在的群列表选择目标群，并提供「发送测试消息」
- 告警发送结果记入操作日志，操作者为 `system:alert`

## 变更

- 健康检测在 SSH 端口可达时，额外探测节点上 TCP 类协议的代理端口，并回写节点的 Xray 运行状态

## 配置前提

1. 系统设置中已启用飞书集成并填写 App ID / App Secret
2. 把机器人拉进目标群
3. （可选）为飞书应用开通 `im:chat:readonly` 权限，用于在设置页列出群；未开通时可手动填写群的 chat_id
4. 健康检测需开启（默认 120 秒一次）。按默认阈值，节点异常约 6 分钟后告警

## 升级

- 新增 `node_alert_states` 表，自动迁移
- 告警默认关闭，升级后行为不变
- 无破坏性变更，无需更新节点端
