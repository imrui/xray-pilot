# xray-pilot v0.5.3

更换系统 Logo。

## 变更

- **新 Logo「节点拓扑 X」**：四个节点经中心枢纽连成 X，对应「Xray」与节点管理。侧栏、登录页、浏览器标签图标、订阅页同步更换
  - 面板内 Logo 跟随主题主色，亮色 / 暗色主题自动切换
  - 浏览器标签图标为小尺寸加粗版，跟随系统明暗切换颜色
  - 订阅页保持绿色主色
- 仓库新增 `docs/brand/` 飞书机器人头像（512×512，绿色 / 蓝色两版），可在飞书开放平台「应用信息 → 应用图标」上传替换
- 移除前端模板遗留的未使用文件 `icons.svg`

## 升级

- 无数据库变更，无破坏性变更，无需更新节点端
- 浏览器可能缓存旧的标签图标，强制刷新后生效
