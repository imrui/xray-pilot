# xray-pilot v0.4.6

一键更换节点服务器：节点故障换机 / 换 IP 时，**保留全部分组关联、协议密钥与节点级覆盖**，客户端订阅无需更换。

## 新增

### 更换服务器（节点列表 → 行菜单「更换服务器」）

节点 VPS 故障或迁移时，之前只能删掉节点重新接入——分组关联、Reality 私钥、端口/SNI 覆盖全部丢失，客户端订阅里的节点也会失效。本版提供两种一键更换方式：

**仅更换 IP**（服务器没换，如迁移弹性 IP）：

- 直接输入新 IP 保存，节点自动进入待同步状态
- 自动清理旧 IP 的 known_hosts 条目
- 配置了域名的节点会提示手动更新 DNS 解析

**更换服务器（重装接入）**（换了一台新机器）：

- 复用 v0.4.0 的一键接入流程：生成一次性 token + curl 命令，在新机执行即可
- 脚本自动装 xray、写入 panel 公钥、注册回 panel
- 注册时**更新现有节点**（IP / SSH / xray 版本）而非新建记录——节点 ID 不变，分组、协议密钥（Reality 私钥）、端口/SNI 覆盖原样保留
- 新机 SSH 可达时**自动触发一次配置同步**，节点最快速度恢复服务
- 走域名连接的节点改完 DNS 后客户端完全无感；走 IP 直连的刷新订阅即可

两种方式均保证**订阅链接不变、节点密钥不变**。

## 改进

- 一键接入 / 更换服务器对话框的「复制命令」按钮改为实心主色按钮，深色代码框中更醒目

## 安全

- 更换模式 token 沿用一键接入的全部安全约束：一次性、默认 10 分钟 TTL、首次访问 IP 绑定
- 注册时先占用 token 再更新节点，并发重复注册只会成功一次

## 升级

- 无破坏性变更；`node_install_tokens` 表新增 `replace_node_id` 列（AutoMigrate 自动处理，老数据零侵入）
- 装机脚本 `node-bootstrap.sh` 无需更新，新旧模式共用同一脚本
