# xray-pilot v0.9.0

## 新增

- 节点可绑定 Cloudflare 已有的 A 或 AAAA 记录。手动修改 IP 或一键换机后，面板自动更新 DNS。检测到记录被外部修改时，会提示管理员重新核对绑定。
- 内网中转订阅可按用户配置，用户能从个人订阅页或飞书获取地址。个人页和后台支持按客户端格式复制链接、保存带用户名的二维码。
- 仪表盘保留升级后删除节点的最后名称和 ID，方便识别历史流量。升级前已删除的节点仍按 ID 展示。

## 从 v0.8.0 升级

- 备份数据库并保留原 MasterKey，替换面板程序后重启服务。数据库自动迁移。
- 节点 DNS 同步和内网中转订阅默认关闭，可在系统设置中按需启用。
