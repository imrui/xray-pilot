# xray-pilot v0.4.7

节点列表可用性升级 + 线上问题修复：服务端筛选、健康状态可视化、更新日志入口，修复批量删除锁冲突与地址空格导致的订阅异常。

## 新增

### 节点列表服务端筛选

- 关键字 / 同步状态 / 地区 / 所有者筛选全部下沉到服务端，**跨全部分页生效**（此前只能过滤当前页数据）
- 地区 / 所有者下拉选项改从全量数据取值（新增 `GET /api/nodes/filter-options`），不再随翻页残缺
- 搜索输入 300ms 防抖；筛选条件变化自动回到第 1 页

### 节点健康状态可视化

- 节点名称前新增健康圆点，语义与仪表盘一致：绿 = 检测通过、红 = 检测失败、灰 = 从未检测；悬停显示延迟与最后检测时间
- 异常节点在地区行追加红色「健康检测异常」提示
- 新增「健康度」筛选（健康 / 检测异常 / 未检测），一键只看待修复节点

### 连接地址快速复制

- 节点列表连接地址列的 IP 和域名各自带复制按钮，点击即复制并 toast 确认

### 更新日志

- 头像菜单新增「更新日志」，侧栏左下角版本号也可点击打开
- 更新日志抽屉：左侧版本导航 + 右侧内容，点击版本号快速定位，滚动时自动同步高亮
- release-notes 编译期内嵌进二进制（新增 `GET /api/system/release-notes`），内容与运行版本严格一致
- 登录页版本号点击跳转 GitHub Releases 页面

### 订阅节点重复自检

- 系统自检新增「订阅节点重复检测」：检出除名称外完全相同的订阅节点。此类节点会被 V2rayN / Shadowrocket 等客户端更新订阅时自动去重，表现为"订阅页有 N 个节点、客户端只有 N-1 个"

## 修复

- **批量删除节点报 "database is locked (5) (SQLITE_BUSY)"**：SQLite 连接池收敛为单连接串行化写入，并设置 busy_timeout 兜底；前端批量删除改为串行执行并逐个汇报成功 / 失败明细
- **节点 IP / 域名混入首尾空格导致订阅地址异常**（如 `" tw03.xxx"` 会被客户端解析失败而丢弃）：前端保存与后端 service 层双层自动去除所有文本字段首尾空格；存量脏数据重新保存节点即可修正，并会正确触发重新同步与 known_hosts 清理

## 变更

- Go 升级至 1.26.6，全量依赖更新（gRPC v1.83.1、GORM v1.31.2、modernc.org/sqlite v1.57.0、golang.org/x/crypto v0.55.0 等）
