# xray-pilot v0.5.0

多管理员账号系统：管理员入库、两级角色、面板内增删改与改密；操作日志全量记录操作者并支持按来源筛选。

## 新增

### 多管理员账号

- 管理员账号改为存数据库，在「系统设置 → 管理员账号」新建、启用/禁用、重置密码、删除
- 两级角色：**超级管理员**可管理账号；**管理员**拥有全部业务操作权限，仅可改自己密码
- 头像菜单显示当前身份，新增「修改密码」（需旧密码）
- 登录失败会记入操作日志（密码错误 / 账号已禁用）
- 安全护栏：至少保留一个启用的超级管理员；对自己不能删除、禁用、修改角色或重置密码（自己的密码走头像菜单「修改密码」）；禁用或删除账号后其已登录会话立即失效

### 操作日志来源

- 每条日志记录操作者：管理员用户名、后台调度任务、节点接入脚本或飞书回调
- 日志页新增「来源」列，并可按管理员操作 / 后台调度 / 节点接入 / 飞书回调一键筛选

## 修复

- **下载数据库备份超时失败**：备份文件较大（数十 MB）经 CDN 或反向代理传输时，前端 10 秒请求超时导致下载中断。下载请求不再限制超时

## 变更

### 主题配色调整

- 主色由绿色改为蓝色；暗色模式从纯黑改为中性锌灰三档（侧栏与顶栏最深、内容区其次、卡片最浅），去掉厚阴影；亮色模式改冷灰底 + 白卡片
- 侧栏当前页：亮色为蓝色实心，暗色为中性浅灰，彩色只用于按钮与状态
- 成功 / 警告 / 危险等状态色统一走主题变量，暗亮两态各自校准；亮色下的次要文字、警告 / 成功文字色按 WCAG AA 重新取值
- 顶栏不再与卡片同色：亮色下与页面同底，暗色下与侧栏同色连成框架
- Inter / IBM Plex Mono 字体改为随二进制自托管，不再从 Google Fonts 加载（国内网络下不再因外链阻塞首屏）；字体栈补齐中文回退
- 界面中残留的 emoji 图标（锁定、警告）统一换为线性图标，避免跨平台外观不一致

### 页面布局统一

- 所有页面第一行统一为工具栏（搜索 / 筛选 / 主操作），去掉与顶栏重复的页内说明文字
- 去掉多处"卡片套卡片"：列表页表格不再外包一层卡片，右侧说明与设置页的列表、飞书配置区改为分隔线分组
- 对齐修正：仪表盘「最近操作 / 节点健康」与上一行流量卡共用列线、两卡头部等高；操作日志页来源筛选提到第一行，表格与右侧说明卡顶部齐平

### 仪表盘与提醒

- 「仪表总览」改名「仪表盘」；指标卡副文案不再用绿色，只在异常时标红
- 「节点待同步」提醒从内容区横幅改为顶栏状态胶囊，点击展开明细与「一键同步」；侧栏「节点管理」同时显示待处理数量角标。内容区不再被挤占

### 系统设置页重构

- 原单页长滚动拆为 5 个分组，作为侧栏「系统设置」的二级菜单：运行状态、节点与同步、订阅与通知、数据备份、管理员。每组有独立地址（如 `/settings/backup`），刷新后停留在当前组
- 配置类分组共用底部保存条，显示待保存状态并支持撤销；只读诊断与管理员账号不再出现保存按钮
- 自动备份间隔移到「数据备份」分组，与备份目录、保留天数放在一起
- 切换分组时若有未保存改动会先确认，避免误丢修改
- 协议配置页「密钥 / 锁定」按钮改为与「编辑」同级的中性样式

## 升级

- 新增 `admin_users` 表，自动迁移。**首次启动**把 `config.yaml` 的 `admins` 段写入数据库，第一个账号为超级管理员；之后 `admins` 段被忽略，请在面板内维护账号
- **升级后所有已登录会话失效，需重新登录一次**（新版 token 携带账号 ID）
- `users` 表无变更；v0.5.0 之前的历史日志「来源」列为空
